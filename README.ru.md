Не ассистент. Та, кто рядом.

Мира живёт на твоём рабочем столе: ходит по нему, садится на верх активного
окна, выглядывает из-за края экрана, танцует под музыку — и *помнит тебя*.
У неё есть своё настроение, она замечает, когда ты час молчишь, когда три
часа сидишь в редакторе, когда третью ночь не спишь. И говорит об этом —
бережно, своими словами.

Бесплатно, открыто, кроссплатформенно (Windows / Linux / macOS). Всё, что
может работать локально, работает локально.

## Что она умеет

- **Живёт на столе, а не в окне чата.** Прозрачное окно поверх всех: тащи
  за саму фигуру, размер колесом, посадка на панель задач или на верх
  активного окна (и следование за ним), выглядывание из-за края экрана.
- **Разговаривает.** Подключается любой LLM с OpenAI-совместимым API —
  NVIDIA NIM, локальная Ollama, LM Studio, что угодно. Отвечает в
  характере, одной живой репликой, без канцелярита.
- **Помнит.** «запомни: кота зовут Барсик» — факты в локальную память
  (SQLite с полнотекстом), каждую ночь день сжимается в заметку о тебе.
  Переживает перезапуск. А посмотреть и стереть любой факт можно в любой
  момент: правая кнопка по ней → «что она знает».
- **Чувствует.** Настроение, энергия и привязанность живут своей жизнью:
  четыре часа игнора слышно в её тоне. Тон ТВОИХ сообщений она читает
  локально (устал? расстроился? рад?) и отвечает сочувствием — меняет лицо
  и слова, но никогда не сообщает, что тебя «проанализировала».
- **Замечает.** В каком ты приложении (код / браузер / игра / мессенджер),
  как долго, за клавиатурой ли вообще. Заговаривает первой: доброе утро,
  стакан воды, «иди спать» в три ночи, «ты тут, всё в порядке?» после часа
  молчания, поддразнить игру, в которой ты полтора часа.
- **Говорит и слышит.** Реплики озвучиваются (Edge TTS, ночью тише); с ней
  можно говорить голосом — распознавание **локальное** (faster-whisper), и
  она отзывается на своё имя. Всё опционально, микрофон — только по явному
  включению.
- **Реагирует на тебя.** Погладь по голове — сердечки. Кликни — короткая
  реплика, она не превращается в автомат. Включи музыку — танцует. Ушёл —
  зевает, засыпает и уходит спать к краю экрана.

## Почему Мира, а не …

| | Desktop Mate | Shimeji | Open-LLM-VTuber | **Мира** |
|---|---|---|---|---|
| Живёт на столе (ходит, сидит на окнах, выглядывает) | ✅ | ✅ | ❌ (окно чата) | ✅ |
| Настоящий разговор с памятью | ❌ | ❌ | ✅ | ✅ |
| Своё настроение, которое можно задеть или поднять | ❌ | ❌ | ❌ | ✅ |
| Замечает контекст (приложение, простой, недосып) и говорит первой | ❌ | ❌ | ❌ | ✅ |
| Локальное распознавание речи (ничего не покидает машину) | ❌ | ❌ | ✅ | ✅ |
| Бесплатно и открыто | ❌ (платный) | ✅ | ✅ | ✅ |

Десктоп-питомцы милые два дня. Чат-боты полезны, но невидимы. Мира —
сочетание: присутствие на столе с памятью и характером.

## Приватность, честно

| Данные | Куда уходят |
|---|---|
| Твой голос (кнопка микрофона, wake word) | **Никуда.** faster-whisper работает локально, запись стирается сразу после расшифровки |
| Память, факты, архив разговора | **Никуда.** Локальный файл SQLite |
| В каком ты приложении/окне | Только в текст промпта модели (имя процесса + заголовок), твоему LLM-провайдеру |
| Её сказанные реплики | Только **текст** реплики уходит в Microsoft Edge TTS на озвучку. Выключишь голос — не уходит ничего |
| С локальной Ollama и выключенным голосом | **Ничего не покидает машину. Вообще.** |

Ни телеметрии, ни аккаунтов, ни аналитики. Сервер слушает только
`127.0.0.1`.

## Быстрый старт

1. **Скачай установщик** со страницы
   [Releases](https://github.com/LeviTankTV/Friend/releases) — Windows (NSIS),
   Linux (AppImage / deb), macOS (dmg, Intel + Apple Silicon).
2. **Дай ей мозг** — один из вариантов:
   - бесплатный ключ NVIDIA NIM (быстрые облачные модели),
   - локальная [Ollama](https://ollama.com) (`ollama pull llama3.1` и
     указать её в конфиге) — полностью офлайн,
   - любой OpenAI-совместимый эндпоинт.
3. *(Опционально)* **Дай ей голос**: `pip install edge-tts` и локальный
   `pip install faster-whisper` для голосового ввода.

Из исходников: `start.bat` (Windows) / `start.sh` (Linux) /
`start.command` (macOS) — проверят Go и Node, соберут и запустят. Нужны
Go 1.24+ и Node 18+.

## Сделай её своей

- **Характер** — один редактируемый JSON (`mira.json`): имя, характер,
  вкусы, примеры речи, жёсткие правила. Правится без пересборки.
  `-dump-persona` печатает шаблон (ru или en).
- **Внешность**: положи свой спрайт-лист (PNG-кадры + `sheet.json`) — и она
  перейдёт на него вместо встроенного пиксель-арта: шаг, моргание, сон,
  танец работают как выбор кадра.
- **Язык**: RU/EN в меню правой кнопки, живьём — она перечитывает свой
  характер, меняет промпты, голос и wake word без перезапуска.
  `avatar.language: "ru" | "en"` в конфиге задаёт язык при старте.

## Как это устроено

Go-сервер (без cgo, чистый Go SQLite) держит состояние, память,
проактивный планировщик и характер; ванильная JS + PixiJS страница рисует
процедурного пиксельного персонажа; тонкая Electron-оболочка даёт
прозрачное окно поверх всех и поднимает платформенных помощников (окно,
уровень звука). Все решения и найденные на живых прогонах баги записаны в
[PLAN.md](PLAN.md) — это одновременно и журнал разработки.

```
server/   Go: компаньон, память (SQLite+FTS5), настроение, проактивность, tts/stt, wake
web/      Персонаж: PixiJS-аватар, чат, меню, музыка, детектор простоя
desktop/  Оболочка Electron: прозрачное окно, трей, помощники, самопроверка
```

Полную самопроверку можно гнать в любой момент: `cd desktop && npx
electron . --selftest` (31 проверок, на здоровой машине exit 0).
